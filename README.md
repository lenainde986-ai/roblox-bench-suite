# AznoCheats

Private Roblox suite — Bee Swarm + Lumber Tycoon, modern executor skeleton, Hyperion notes.

## Quick Start

1. Get a current high-sUNC executor (Volt / Potassium recommended)
2. Join the game
3. Execute the matching script from `/cheats`
4. Enter your AuthKey when prompted
