# AznoCheats

Private unified loader — one menu, Games tab, both scripts inside.

## Quick Start

1. Open `cheats/AznoCheats.lua`
2. Set your key:
```lua
local AUTH_KEY = "your-private-key"
```
3. Execute in your executor (Volt / Potassium recommended)
4. Enter key → menu opens
5. **Games** tab has:
   - Bee Swarm Simulator (all features)
   - Lumber Tycoon 2 (all features)
6. Toggle **Load BSS** or **Load LT2** then enable the features you want
7. INSERT to show/hide menu
